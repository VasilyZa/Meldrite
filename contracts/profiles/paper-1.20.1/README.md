# Locked Paper 1.20.1 contract

`api-index.json` is the manifest for the complete, losslessly compressed classfile inventory. Each artifact has a coordinate, unique version, canonical URL, binary hash, shard hash and class/symbol count. `verifyContracts` re-extracts every shard from the verified locked JAR; it does not trust the committed counts. No package prefix excludes public Paper API. Internal annotations preserve `API_INTERNAL_SUPPORT`. Every inherited operation has its own receiving-owner symbol and declaring-owner metadata.

The public classpath uses nearest-definition mediation, with declaration order breaking depth ties. Original dependency edges and conflicting historical versions remain in the artifact lock. Canonical providers are listed in manifest order. Duplicate class identities fail the audit. The actual Java 17 multi-release view is inventoried; alternative class entries also remain hashed resources. Java 17 is the only runtime target in this round.

`bindings.json` assigns every root API symbol to an explicit status and owner. `NOT_APPLICABLE` means the exact upstream concrete/default implementation or JVM annotation supplies the symbol, and makes no server behavior claim. Abstract server operations default to `UNSUPPORTED`. Public dependency symbols have individual bindings in hashed `vendor-bindings/` shards and preserve `TRANSITIVE_API`. Optional provider-specific inheritance unavailable in this public classpath is recorded under `unresolvedHierarchy` with `CLASSPATH_UNAVAILABLE`; it is neither invented nor promised as linkable.

`domain-batches.json` names every server obligation, adapter file and scenario prerequisite. Paths are planned targets, not claims that those adapters exist. `ProfileAdapterGenerator` generates checked typed overrides for determined interface signatures, explicit unsupported throws or named typed delegate expressions. Generic owner substitution, ambiguous covariant return selection and concrete factories require explicit profile policy; generation rejects them instead of introducing reflective proxies.

A supported/partial symbol needs a compiled concrete target with the correct symbol, source/class hashes, named behavior and regression evidence, current report hash and an actually passed JUnit testcase. The target must be assignable to the API owner under the actual locked classpath, with the same method descriptor. A workspace hash covers service, adapter, bridge, fixture, configuration and contract inputs, so a changed service invalidates prior evidence. Empty/default-value implementations must fail a semantic assertion; static ABI inspection alone cannot prove arbitrary behavior. The audit refuses missing, failed, skipped or stale evidence. Partial bindings enumerate limits. No server behavior is supported at the F3 gate.

`lifecycle.json` records architectural ordering constraints and explicitly pending exact server traces. Runtime tasks must resolve descriptor/lifecycle semantics against the pinned baseline. Server/Craft extraction has a separate `SERVER_IMPLEMENTATION` provenance and remains a C1/C3 prerequisite, outside the public API. A future version supplies a separate profile and version implementation; this round creates, builds and tests no future game implementation.

`./gradlew generateContracts --offline` regenerates the inventory from existing locked bytes. The generator refuses to overwrite SUPPORTED/PARTIAL bindings; inventory changes then require explicit reconciliation instead of lowering support statuses. `./gradlew verifyContracts --offline` only verifies and writes reports under `build/`.
